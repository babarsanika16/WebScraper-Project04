# Web Scraper for Headlines & Quotes

## Project Overview
This project is a Python-based web scraper that collects
quotes, author names and tags from a practice website.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- JSON

## Website Used
https://quotes.toscrape.com

## Features
- Fetches website data using HTTP requests.
- Extracts quotes, authors and tags.
- Collects data from multiple pages.
- Saves data in JSON and TXT formats.
- Displays scraping statistics.

## How to Run

1. Install Python.
2. Install required libraries:

   pip install requests beautifulsoup4

3. Run the program:

   python scraper.py

## Output Files
- quotes.json
- quotes.txt

## Responsible Scraping
This project uses a website made for scraping practice.
It includes a request timeout and a one-second delay
between page requests.
